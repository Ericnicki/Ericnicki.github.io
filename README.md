# Keqi Ni 倪珂祺

Personal academic website: https://Ericnicki.github.io

Research interests: meta-learning exploration, LLM-guided policy learning, and memory-based reinforcement learning for dynamics adaptation.

## Website

- `index.html`: portrait, institutions and research interests.
- `research.html`: research experience and publications.
- `project.html`: selected projects in TTT memory RL and cross-modal radar–IMU JEPA.
- `cv.html`: CV viewer.
- `assets/`: selected portrait, videos, curves and model architecture diagrams.

## Research code

- `research/gmp-t4/`: iterative-pushing TTT/RL source snapshots and evaluation evidence.
- `research/radar-gesture/`: compact radar–IMU JEPA implementation and radar-only baseline.

The source directories preserve research provenance and upstream attribution. The iterative-pushing release requires its original environment and bound checkpoints; see its README for reproduction limits. Datasets and large model weights are not included.

## Local preview

Run `python3 preview.py` and visit http://127.0.0.1:8787. The preview server supports video seeking. GitHub Pages publishes the static files from `main` at the repository root.
